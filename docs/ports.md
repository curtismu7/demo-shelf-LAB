## New apps: one port each, from the packed range

New standalone apps take ports 7800-7999, one at a time: run `npm run ports -- --next` for the next free one, then register the app in data/demos.json. Declare only the ports the app really uses, not a block. Existing apps keep the ports they have.

Packed range: 5 of 200 in use, 195 free.
